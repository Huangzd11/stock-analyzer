## 2. 包职责说明

| 包 | 职责 |
|----|------|
| `domain` | 无外部依赖的纯逻辑；所有指标/预测算法可单测 |
| `application` | 组合端口完成用例；事务边界、编排 |
| `ports` | `typing.Protocol` 定义契约 |
| `infrastructure` | 第三方库、DB、HTTP、文件系统 |
| `interface` | Click/Typer CLI、FastAPI 路由 |

## 3. 命名约定

- 模块/函数：`snake_case`
- 类：`PascalCase`
- 测试文件：`test_<module>.py`
- 测试函数：`test_<行为>_<条件>_<期望>`

## 4. 配置约定

- 使用 `pydantic-settings` 从环境变量 / `.env` 加载
- 敏感项：`API_KEY`、`DATABASE_URL` 不入库
- 示例见根目录 `.env.example`

## 5. CLI 命令草案（MVP）

```bash
# 爬取日 K
stock-analyzer crawl --symbols 600519,000001 --start 2024-01-01

# 技术分析
stock-analyzer analyze --symbol 600519 --indicators ma,macd,rsi

# 走势预测
stock-analyzer predict --symbol 600519 --days 30 --strategy ma_trend

# 生成图表
stock-analyzer chart --symbol 600519 --output ./output/600519.html
```
