# 04 — 数据模型

## 1. 领域实体

### 1.1 Stock（股票基础信息）

| 字段 | 类型 | 说明 |
|------|------|------|
| symbol | str | 代码，如 `600519` |
| name | str | 简称 |
| market | enum | `SH` / `SZ` / `BJ` |
| industry | str? | 行业 |
| list_date | date? | 上市日期 |

### 1.2 Quote（行情 K 线）

| 字段 | 类型 | 说明 |
|------|------|------|
| symbol | str | 股票代码 |
| trade_date | date | 交易日 |
| open | Decimal | 开盘价 |
| high | Decimal | 最高价 |
| low | Decimal | 最低价 |
| close | Decimal | 收盘价 |
| volume | int | 成交量 |
| amount | Decimal? | 成交额 |
| adj_factor | Decimal? | 复权因子 |

**约束**：`(symbol, trade_date)` 唯一；价格 > 0；high ≥ max(open, close, low)。

## 2. 存储 Schema（SQLite MVP）

```sql
-- 股票基础表
CREATE TABLE stocks (
    symbol TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    market TEXT NOT NULL,
    industry TEXT,
    list_date TEXT,
    updated_at TEXT NOT NULL
);

-- 日 K 表
CREATE TABLE daily_quotes (
    symbol TEXT NOT NULL,
    trade_date TEXT NOT NULL,
    open REAL NOT NULL,
    high REAL NOT NULL,
    low REAL NOT NULL,
    close REAL NOT NULL,
    volume INTEGER NOT NULL,
    amount REAL,
    adj_factor REAL,
    PRIMARY KEY (symbol, trade_date),
    FOREIGN KEY (symbol) REFERENCES stocks(symbol)
);

CREATE INDEX idx_daily_quotes_symbol_date ON daily_quotes(symbol, trade_date DESC);

-- 爬取任务审计（可选）
CREATE TABLE crawl_jobs (
    id TEXT PRIMARY KEY,
    tenant_id TEXT NOT NULL,
    status TEXT NOT NULL,  -- pending|running|done|failed
    payload_json TEXT NOT NULL,
    created_at TEXT NOT NULL,
    finished_at TEXT
);
```

## 3. 端口接口契约（摘要）

### IQuoteSource

```python
class IQuoteSource(Protocol):
    async def fetch_daily(
        self, symbol: str, start: date, end: date
    ) -> list[Quote]: ...

    async def fetch_stock_info(self, symbol: str) -> Stock: ...
```

### IQuoteRepository

```python
class IQuoteRepository(Protocol):
    async def upsert_quotes(self, quotes: list[Quote]) -> int: ...
    async def get_quotes(
        self, symbol: str, start: date, end: date
    ) -> list[Quote]: ...
```
